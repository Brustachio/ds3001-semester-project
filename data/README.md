## Data Provenance & Documentation

This project uses data on reported crime incidents in Washington, D.C., to classify offenses as violent or property crimes based on temporal, geographic, and tactical features.

### Original Provider & Source URL

- **Provider:** DC Metropolitan Police Department (MPD)
- **Source:** Open Data DC API
- **URL:** `https://opendata.dc.gov/` (Search: "Crime Incidents")

### Date and Method of Access

- **Method:** Direct public CSV download from the Open Data DC web portal. The data is entirely public and unencumbered by licensing barriers.
- **Date:** [Insert the exact date you downloaded the files, e.g., October 20, 2026]

### Exact Files Used

- **`Crime_Incidents_in_2024.csv`**: Raw incident reports for the year 2024.
- **`Crime_Incidents_in_2025.csv`**: Raw incident reports for the year 2025.
- **`Crime_Incidents_Clean+Combined.csv`**: The combined, cleaned analytic sample generated by our project pipeline.

### Steps to Recreate the Analytic Data

To reproduce the clean dataset from the raw files:

1. Ensure both `Crime_Incidents_in_2024.csv` and `Crime_Incidents_in_2025.csv` are in this `data/` directory.

2. Open `main_notebook.ipynb` in the project root.

3. Run the notebook from top to bottom. The script will automatically read both CSV files, map the 9 `OFFENSE` classifications to a binary target (`Violent` vs `Property`), parse the `START_DATE`, coerce numeric coordinates (`LATITUDE`, `LONGITUDE`), drop rows missing critical spatial/temporal data, and output the final `Crime_Incidents_Clean+Combined.csv` file into this directory.
